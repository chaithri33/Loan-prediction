# Loan Default Prediction Analysis

A machine learning project focused on analyzing loan applicant data and predicting the likelihood of loan default using data analysis, visualization, and classification techniques.

Project Overview
This project explores a loan dataset to identify patterns that contribute to loan default risk. The workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, visualization, and machine learning model building.
The goal of the project is to help understand how factors such as income, credit history, loan amount, and other applicant details influence loan repayment behavior.
