# 💳 Loan Default Prediction Analysis

A machine learning project focused on analyzing loan applicant data and predicting the likelihood of loan default using data analysis, visualization, and classification techniques.

---

## 📌 Project Overview

This project explores a loan dataset to identify patterns that contribute to loan default risk. The workflow includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Data visualization
- Machine learning model building

The goal of this project is to understand how factors such as income, credit history, loan amount, and applicant details influence loan repayment behavior.
